# Code of Conduct

This project is a small community effort built around respectful technical
collaboration.

Be welcoming, patient, and specific. Critique ideas and code, not people.
Respect different experience levels, languages, identities, and operating
environments. Do not publish private data, credentials, chat content, or other
people's identifying information.

Harassment, threats, discrimination, deliberate disruption, and unwanted
disclosure of private information are not accepted. Maintainers may edit,
hide, or remove contributions and restrict participation when needed to keep
the project safe.

For ordinary project concerns, open an issue. For sensitive security or
conduct concerns, use the private reporting channel described in
[SECURITY.md](SECURITY.md).
